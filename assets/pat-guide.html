Hướng dẫn tạo GitHub PAT cho Copilot CLI

Dùng cho mục "GitHub Copilot CLI (agent 'Copilot CLI' trong Gemini)" ở wizard cài đặt telecode.

Bước 1 — Điền thông tin token

Đặt Token name dễ nhận biết (vd telecode), Description tuỳ chọn, chọn đúng Resource owner là tài khoản GitHub của bạn, và đặt Expiration.

Bước 2 — Bật quyền "Copilot Requests"

Giữ nguyên Repository access = Public repositories (không cần đổi). Quyền cần bật nằm ở khối Account phía dưới (không phải Repository access) — bấm "+ Add permissions", chọn "Copilot Requests", rồi bấm "Generate token".

Sau khi có token, copy và dán vào ô "GitHub Copilot CLI" trong wizard cài đặt.
